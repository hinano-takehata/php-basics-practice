# php-basics-practice

## 概要

COACHTECH 教材 Tutorial 7-1 「PHPの基礎　ハンズオン演習」で作成した成果物です。
商品の価格、数量、消費税率を使って、合計金額を計算する、商品価格計算プログラムを作成しました。

## 使用技術

- PHP 8.2

## 学んだこと

・変数の定義と整数と文字列の使い分け方（シングルクォーテーションをつけるかつけないか）
・四則演算を使った計算処理、消費税の計算の仕方と表示の仕方
・HTMLで使用したタグ<strong><br>を組み合わせるやり方
・はじめは文字列と変数をピリオドで連結していなくて、ブラウザで確認したときは、入力した数式がそのまま表示された。それまでのチュートリアルの実務での使用例のコードと自分が入力したコードを見比べて違いに気づいたので、修正したことで解決した。

## 動作確認

対応するURLにアクセスし、提示されている完成イメージと照らし合わせる。
また、そのあと、商品価格を変更し、価格変更したら消費税や合計金額が変更するか確認し、値を元に戻した。
